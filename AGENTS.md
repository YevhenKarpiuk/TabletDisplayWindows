# Инструкции проекта

Перед любой работой прочитай [CONTEXT.md](CONTEXT.md), затем соответствующие документы из `doc`.

Поддерживай `CONTEXT.md` кратким. Обновляй его только при изменении назначения, архитектуры, протокола, ключевых ограничений или текущего этапа проекта.

Не меняй сетевой протокол односторонне: изменения должны быть отражены в `doc/PROTOCOL.md` этого проекта и в парном Android-проекте.
