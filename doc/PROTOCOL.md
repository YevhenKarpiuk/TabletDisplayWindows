# TabletDisplay wire protocol

Статус: wire format ещё не зафиксирован; этот файл должен оставаться синхронным в Windows- и Android-репозиториях.

Уже согласовано для MVP:

- transport: один двунаправленный TCP-сеанс через `adb forward`;
- Android listener: `127.0.0.1:27183`;
- начальная версия протокола: `1`;
- видео: H.264/AVC Annex B;
- порядок байтов, заголовок, типы сообщений и лимиты будут определены перед реализацией parser/serializer.
