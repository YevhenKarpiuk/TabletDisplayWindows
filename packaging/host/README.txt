TabletDisplay Host Portable 0.1.5

UK
- Підключіть Android-планшет з увімкненим USB debugging.
- Встановіть та запустіть TabletDisplay APK на планшеті.
- Запустіть TabletDisplay.exe. Програма працює в системному треї.
- У меню іконки ввімкніть «Автозапуск із Windows», щоб запускати Host після входу в Windows.
- Коли Windows вимикає дисплеї для енергозбереження, зображення на планшеті стає чорним; після пробудження потік відновлюється автоматично.
- Віртуальний монітор з'являється у Windows лише після підключення Host до застосунку на планшеті та зникає після розриву зв'язку.
- Для портретного режиму виберіть для TabletDisplay «Орієнтація дисплея: Книжкова» у параметрах Windows і поверніть планшет.
- Натисніть іконку в треї та виберіть «Вихід», щоб завершити роботу.

EN
- Connect the Android tablet with USB debugging enabled.
- Install and start the TabletDisplay APK on the tablet.
- Run TabletDisplay.exe. The app stays in the system tray.
- Enable “Start with Windows” in the tray menu to launch the Host after signing in to Windows.
- When Windows turns the displays off to save power, the tablet turns black; streaming resumes automatically after wake-up.
- The virtual monitor appears in Windows only after the Host connects to the tablet app and disappears when that connection is lost.
- Up to four tablets can be connected at once. Each gets its own virtual monitor (Monitor 1..4 in the tray menu) and keeps it on reconnect; touches from different tablets share one Windows mouse cursor.
- For portrait mode, set TabletDisplay to “Display orientation: Portrait” in Windows Settings and rotate the tablet.
- Click the tray icon and choose “Exit” to quit.

The bundled Android platform-tools are used automatically. No installation is required.
